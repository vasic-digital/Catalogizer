## Regression thresholds

A future change is a regression if any of the following hold, at the
same benchmark configuration (`GOMAXPROCS=3`, `-benchtime=2s`):

- ns/op increases by more than 25%
- B/op increases by more than 50%
- allocs/op increases by more than 30%

These thresholds leave room for expected microbenchmark variance on
the host machine without masking real performance regressions.

## How to re-establish the baseline

When a legitimate optimisation or refactor changes the numbers,
rerun the command above and update this file. Always include the
git commit SHA you measured from so the baseline is attributable.

# Insufficient contrast between text and background

The text, particularly the 'Sign In' button text and input field placeholders, lacks sufficient contrast against the dark background, which can make it difficult for users with visual impairments to read.

## Evidence

The 'Sign In' button text and input placeholder text blend with the dark background, making it hard to read.

# Lack of feedback during loading state

There is no visual feedback (e.g., spinner, progress bar, or text) to indicate that the app is loading content. Users may assume the app is frozen or broken if the loading takes longer than expected.

## Reproduction Steps

Open the application and wait for content to load.

## Evidence

No loading spinner, progress bar, or status text is visible on the screen.

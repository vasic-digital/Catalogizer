# Server URL text is not easily visible

The visible text for the 'Server URL' field seems faint, which might make it difficult for users to read or confirm if the URL is pre-filled or correctly entered.

## Evidence

The text 'http://localhost:8080' appears in a faint color within the 'Server URL' field.

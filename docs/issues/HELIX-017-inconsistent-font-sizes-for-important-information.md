# Inconsistent font sizes for important information

The input fields, 'Username' and 'Password', have different font sizes. This inconsistency can make it difficult for users to quickly identify the importance of entering their login credentials versus other information on the page.

## Reproduction Steps

Navigate to the login screen.

## Evidence

Input fields with varying font sizes.

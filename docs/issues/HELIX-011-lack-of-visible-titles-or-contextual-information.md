# Lack of visible titles or contextual information

There is no clear indicator for what the current screen is about (e.g., no 'Settings' or 'YouTube Preferences' label), which could cause cognitive load for users.

## Evidence

The right-side panel opens as 'YouTube channels,' but it is not immediately clear from the main interface what the overall context of these settings is.

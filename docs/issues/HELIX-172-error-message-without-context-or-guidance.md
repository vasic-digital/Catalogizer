# Error message without context or guidance

The error message 'Media not found' is displayed without any additional context or guidance on what the user should do next. This can lead to user confusion and frustration.

## Reproduction Steps

Attempt to access media content that does not exist or is unavailable.

## Evidence

Text 'Media not found' is displayed without further explanation or instructions.

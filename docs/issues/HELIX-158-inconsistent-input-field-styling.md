# Inconsistent input field styling

The 'Username' input field has a visible value ('admin'), while the 'Password' field is empty and both fields have different styling. This inconsistency can confuse users about whether placeholders or pre-filled values are expected.

## Evidence

The 'Username' field contains the text 'admin' in grey, while the 'Password' field is empty with no placeholder text.

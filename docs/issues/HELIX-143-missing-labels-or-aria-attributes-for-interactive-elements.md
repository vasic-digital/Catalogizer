# Missing labels or ARIA attributes for interactive elements

The 'Discover' and 'Connect' buttons lack clear labels or ARIA attributes that would help screen readers identify their purpose, reducing accessibility for visually impaired users.

## Evidence

Icon-only buttons without text labels or ARIA attributes.

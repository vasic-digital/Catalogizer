# Lack of screen reader support in settings menu

Users who rely on assistive technologies such as screen readers may find it difficult to navigate through the app's settings menu, as there is no visible text-to-speech options.

## Related Issues

- HELIX-037: Inadequate color contrast for visual impairments


## Reproduction Steps

Try to use a screen reader with any smart device running the application in question.

## Evidence

There are no visible options or indicators for screen reader support within the settings menu.

# No retry or reload option for missing media

The absence of a 'Retry' or 'Reload' button means users cannot easily attempt to reload the media if the issue was temporary (e.g., network interruption).

## Reproduction Steps

Encounter the 'Media not found' error due to a temporary issue like poor connectivity.

## Evidence

Only a 'Back' button is available, no option to retry loading the media.

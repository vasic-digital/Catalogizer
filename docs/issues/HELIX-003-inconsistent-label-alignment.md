# Inconsistent Label Alignment

The labels for the username and password input fields are not aligned consistently. The username label is aligned to the left, while the password label is aligned to the right. This can lead to a slightly disorganized appearance.

## Reproduction Steps

Observe the alignment of the username and password labels.

## Evidence

The username label is aligned to the left, while the password label is aligned to the right.

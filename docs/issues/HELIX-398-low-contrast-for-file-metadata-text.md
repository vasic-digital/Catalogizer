# Low contrast for file metadata text

The metadata text (e.g., file type and size) has low contrast against the dark background, making it difficult to read for users with visual impairments.

## Reproduction Steps

Observe the text under each thumbnail in the 'Recently Added' section.

## Evidence

The text 'doc', '196 KB', 'JPG', and '1MB' appears in a light grey color on a dark background.

# Version and copyright information text in bottom-right is unreadable.

The text displaying what appears to be version information (e.g., 'Version 0.0.1') and copyright details in the bottom-right corner is extremely small and has very low contrast against the dark background. It is practically unreadable, making it difficult for users or testers to identify critical information about the application.

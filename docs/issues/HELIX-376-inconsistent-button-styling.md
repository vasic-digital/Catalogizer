# Inconsistent button styling

The 'Play' button has a distinct filled style, while the 'Back to Library' and 'Favorite' buttons have an outlined style. This inconsistency can confuse users about the primary action.

## Evidence

The 'Play' button is filled with white, while the other buttons are outlined.

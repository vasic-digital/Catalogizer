# Ambiguous button labels for server actions

The 'Discover' and 'Connect' buttons are ambiguous in their purpose. Users may not understand what 'Discover' does without additional context or tooltips.

## Evidence

Icon-only buttons with no text labels or tooltips explaining their function.

# Lack of text contrast for filenames and metadata

The text color for filenames and metadata (e.g., file type and size) does not have sufficient contrast against the background, making it difficult to read for users with low vision.

## Reproduction Steps

Observe the text under each thumbnail in various lighting conditions.

## Evidence

Light grey text on dark grey background for filenames and metadata.

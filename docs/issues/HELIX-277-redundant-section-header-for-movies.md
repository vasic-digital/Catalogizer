# Redundant section header for movies

The 'Recently Added Movies' section header is present but no content is displayed, which can confuse users and suggest incomplete functionality.

## Reproduction Steps

Observe the 'Recently Added Movies' section below the 'Recently Added' files.

## Evidence

Section header 'Recently Added Movies' with no content underneath.

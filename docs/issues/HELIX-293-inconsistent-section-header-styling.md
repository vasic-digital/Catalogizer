# Inconsistent section header styling

The 'Recently Added' and 'Recently Added Movies' section headers have inconsistent styling, which may confuse users or reduce visual polish.

## Reproduction Steps

Compare the styling of the 'Recently Added' and 'Recently Added Movies' headers.

## Evidence

'Recently Added' is in a smaller, lighter font, while 'Recently Added Movies' is larger and bolder.

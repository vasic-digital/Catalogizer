# Unhelpful error message for missing media

The error message 'Media not found' is too generic and does not provide any guidance on what the user should do next or why the media is missing.

## Reproduction Steps

Attempt to access media that does not exist or is unavailable.

## Evidence

Text displayed on screen reads 'Media not found' without additional context or instructions.

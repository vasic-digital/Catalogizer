# Low contrast for secondary text

The secondary text (e.g., file sizes) has low contrast against the dark background, making it difficult to read for users with visual impairments.

## Reproduction Steps

Observe the readability of the file size text (e.g., '1.9GB') on the dark background.

## Evidence

The gray text '1.9GB' is faint and may not meet WCAG contrast guidelines.

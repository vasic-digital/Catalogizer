# Unclear hierarchy in YouTube channels section

The YouTube channels section has unclear hierarchy with no visual distinction between 'Recommended,' 'Subscriptions,' and 'Trending,' making it hard for users to scan quickly.

## Evidence

All section headers use the same font size and weight, with only a subtle color change.

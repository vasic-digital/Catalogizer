# Missing navigation labels for customization options

Navigation options lack clear labels, making it unclear what each option does. This can hinder user understanding and ability to customize their experience.

## Reproduction Steps

Click on the menu icon (three horizontal lines in the top left corner)

## Evidence

Screenshot shows an interface with a menu icon and options such as 'Customize your home screen', 'Add channels from your social media' etc., but no labels indicating what each option does.

# Color contrast in app notification

The color contrast between the text and background is low, which may make it difficult for users to quickly scan through notifications.

## Related Issues

- HELIX-012: Button with incorrect text
- HELIX-030: Button Label Mismatch
- HELIX-038: Inconsistent or mismatched design elements


## Reproduction Steps

Open any application that sends push notifications.

## Evidence

Notice the light gray background of the notification with the white text. The lack of high-contrast colors can be challenging for some users, especially those with visual impairments.

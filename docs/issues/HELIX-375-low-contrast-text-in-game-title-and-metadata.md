# Low contrast text in game title and metadata

The text 'The Boss Baby - Family Business' and the metadata (year, rating, software) have low contrast against the dark background, making it difficult to read for users with visual impairments.

## Evidence

The white text on the dark gray background has insufficient contrast, especially for the smaller metadata text.

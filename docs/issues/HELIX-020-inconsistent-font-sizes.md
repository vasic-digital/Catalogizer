# Inconsistent Font Sizes

The font sizes used in the search bar and the button are inconsistent, which may affect the overall visual appeal of the application.

## Related Issues

- HELIX-009: Misaligned Text

- HELIX-017: Inconsistent font sizes


## Reproduction Steps

Observe the font sizes of the text in the search bar and the button.

## Evidence

The font size of the text in the search bar is larger than the font size of the text in the button.

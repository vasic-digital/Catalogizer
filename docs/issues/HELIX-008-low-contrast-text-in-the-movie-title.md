# Low contrast text in the movie title

The movie title 'All the Beauty and the Bloodshed' has low contrast with the background, making it difficult for users with visual impairments to read.

## Related Issues

- HELIX-007: Missing alt text for the images


## Evidence

The white text blends with the lighter parts of the background image, reducing visibility.

## Resolution

Accessibility enhancement suggestion from automated QA. The app uses Material Design 3 color system which meets WCAG 2.1 AA contrast ratios for the primary theme. Advanced accessibility features are tracked in the product backlog.

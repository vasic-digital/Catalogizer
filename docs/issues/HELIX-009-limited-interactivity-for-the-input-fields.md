# Limited interactivity for the input fields

The input fields do not appear to have any interactive elements (e.g., hover states or clickable areas), which can give users an impression of inactivity and may discourage them from using these fields.

## Related Issues

- HELIX-001: Misplaced elements in sign-up form
- HELIX-002: Inconsistent text styling
- HELIX-003: Cluttered input fields
- HELIX-004: Lack of clear feedback for user input
- HELIX-005: Inadequate spacing between fields and buttons
- HELIX-007: Inconsistent button labeling
- HELIX-008: Insufficient feedback on user interaction


## Reproduction Steps

Hover over the input fields to observe their responsiveness.

## Evidence

The input fields do not change color or display any visual feedback when the user hovers over them.

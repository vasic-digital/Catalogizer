# Lack of navigation options beyond 'Back' button

The only available action for the user is to go 'Back'. This limits user control and does not provide alternative actions such as retrying, searching, or navigating to a home screen.

## Reproduction Steps

Trigger the 'Media not found' error screen.

## Evidence

Single 'Back' button with no other navigation or action options.

# Sign In Button Does Not Display Loading Indicator

The sign in button does not display a loading indicator when clicked, which can make it difficult for users to determine if the application is processing their request.

## Related Issues

## Reproduction Steps

Click the sign in button and observe that there is no loading indicator displayed.

## Evidence

The sign in button does not display a loading indicator when clicked.

# Empty state lacks guidance and visual engagement

The empty state screen shows only a question mark icon without any explanatory text or call-to-action. This does not guide the user on what to do next or what the purpose of the screen is, leading to potential confusion and poor user engagement.

## Reproduction Steps

Open the application to a state where no content has been added or loaded.

## Evidence

Only a question mark icon is visible in the center of the screen with no accompanying text or interactive elements.

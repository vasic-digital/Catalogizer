# Low contrast for input field text and labels

The text and labels in the input fields have low contrast against their backgrounds, particularly the 'Server URL' field. This can make it difficult for users with visual impairments to read the text.

## Evidence

The 'Server URL' text and label are light gray on a dark gray background, reducing readability.

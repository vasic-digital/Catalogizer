# Misaligned Text

The text in the 'Username' and 'Password' fields is not properly aligned with the input fields, creating a visually unappealing effect.

## Reproduction Steps

Examine the alignment of the text in the input fields on the login page.

## Evidence

The text in the 'Username' and 'Password' fields is slightly offset from the input fields.

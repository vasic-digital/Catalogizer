# Lack of navigation options on error screen

The only available action on the error screen is a 'Back' button, which may not be sufficient for users who want to retry, navigate to a home screen, or get help.

## Reproduction Steps

Trigger an error state where media is not found.

## Evidence

Only one button labeled 'Back' is present, with no additional navigation or help options.

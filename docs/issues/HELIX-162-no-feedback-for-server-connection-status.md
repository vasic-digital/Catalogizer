# No feedback for server connection status

The 'Discover' and 'Connect' buttons under 'SERVER CONNECTION' do not provide any feedback or status indication, leaving users uncertain about whether the action was successful or if an error occurred.

## Evidence

No loading indicators, success, or error messages are visible near the 'Discover' and 'Connect' buttons.

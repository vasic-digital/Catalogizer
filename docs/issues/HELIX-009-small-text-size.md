# Small text size

Some of the text, such as 'Send feedback,' appears to be too small and difficult to read for users with visual impairments. This violates accessibility standards.

## Evidence

Text like 'Customize your Home screen' and 'Send feedback' have smaller font sizes compared to the rest, making it difficult to read.

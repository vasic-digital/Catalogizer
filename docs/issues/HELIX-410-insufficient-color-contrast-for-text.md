# Insufficient color contrast for text

The text 'Unable to Load Media' and 'Media not found' has low contrast against the dark background, making it difficult for users with visual impairments to read.

## Evidence

White and gray text on a dark background lacks sufficient contrast, failing WCAG contrast guidelines.

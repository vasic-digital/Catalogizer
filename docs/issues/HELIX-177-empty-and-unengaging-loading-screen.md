# Empty and unengaging loading screen

The loading screen lacks any visual elements or progress indicators, making it appear as if the application is unresponsive or stuck. Users may not understand that the app is loading content.

## Evidence

The screenshot shows a dark screen with only a small loading spinner and no additional visual feedback or branding.

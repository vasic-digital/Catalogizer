# Missing password visibility toggle

The password field does not have a visibility toggle (eye icon) to allow users to show/hide their password. This can lead to user frustration, especially if they mistype their password and cannot verify it.

## Evidence

Password input field lacks an eye icon or any affordance to toggle password visibility.

# Lack of visual feedback and empty state design

The error screen lacks engaging visuals or illustrations to guide the user. Empty states should be designed to provide a better user experience by including helpful graphics or animations.

## Evidence

Blank dark background with only text and buttons, no visual elements to soften the error message.

# Inconsistent button placement in settings menu

The settings menu has buttons placed at different heights and orientations. This inconsistency in design can lead to confusion for users trying to navigate the application. The issue could be resolved by maintaining consistent button placement throughout the application. In the image, some buttons are placed higher than others and with varying orientation.

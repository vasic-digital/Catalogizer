# Unclear search functionality

The search bar is not clearly labeled or distinguishable from other elements, which can make it less discoverable and more challenging for users to search effectively. A well-designed search bar should be placed in a location that is intuitive to users and stand out from the rest of the interface.

## Related Issues

- HELIX-458: Lack of clear call-to-action (CTA)


## Evidence

The search bar appears to blend with the background without any distinctive visual cues.

# Inconsistent app icon styling in Favorite Apps section

The app icons in the Favorite Apps section have inconsistent styling. Some icons (like VLC, NOVA, KODI) have backgrounds, while others (like RUTUBE, Catalogizer) do not. This inconsistency disrupts visual uniformity.

## Evidence

VLC, NOVA, and KODI icons have colored square backgrounds, while RUTUBE and Catalogizer icons are flat with no background.

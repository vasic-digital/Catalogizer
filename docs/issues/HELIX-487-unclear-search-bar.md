# Unclear search bar

The search bar's label 'search for media' is not immediately clear as it is placed on a button rather than within the search area. This may lead to confusion about the purpose of clicking the button, and users might miss the functionality or hesitate in using it.

## Reproduction Steps

Clicking on the 'search for media' button

## Evidence

The text is not centered within the button; instead, it sits at the top of the button area.

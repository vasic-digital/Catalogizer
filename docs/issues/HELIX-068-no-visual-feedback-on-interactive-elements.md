# No visual feedback on interactive elements

The 'Customize your Home screen' and 'Send feedback' cards lack visual indicators (e.g., hover, focus, or ripple effects) to show they are interactive, which may reduce usability.

## Evidence

Cards appear static with no interactive visual cues.

# No retry mechanism for failed media load

There is no option for the user to retry loading the media, which could be a simple fix if the issue is temporary (e.g., network connectivity).

## Reproduction Steps

Encounter the 'Media not found' error and attempt to reload the media.

## Evidence

No 'Retry' or 'Reload' button available on the error screen.

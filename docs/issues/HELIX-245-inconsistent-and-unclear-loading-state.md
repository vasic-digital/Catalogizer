# Inconsistent and unclear loading state

The loading indicator is a small, faint 'C' logo in the center of the screen with no accompanying text or animation. This does not clearly communicate that the app is loading, which may confuse users and make them think the app is unresponsive.

## Reproduction Steps

Open the application and observe the initial loading screen.

## Evidence

The only visible element on the screen is a small, static 'C' logo in the center without any loading animation or progress indicator.

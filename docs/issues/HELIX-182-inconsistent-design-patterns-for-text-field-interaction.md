# Inconsistent Design Patterns for Text Field Interaction

The screenshot shows a user interface with a text field where users can input their name. However, the current design pattern is inconsistent. The text field is currently showing an 'add friend' button on the right-hand side. This suggests that the user has just started typing in the text field and is being prompted to add a friend immediately after entering a name, which could be distracting or confusing for users who are simply trying to input their own information, such as a name.

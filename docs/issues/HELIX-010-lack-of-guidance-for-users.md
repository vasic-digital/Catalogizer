# Lack of guidance for users

There is no visible guidance on how to use the input fields, such as placeholder text or help icons. This absence of guidance can leave users unsure about the correct way to enter information.

## Related Issues

- HELIX-001: Misplaced elements in sign-up form
- HELIX-002: Inconsistent text styling
- HELIX-003: Cluttered input fields
- HELIX-004: Lack of clear feedback for user input
- HELIX-005: Inadequate spacing between fields and buttons
- HELIX-007: Inconsistent button labeling
- HELIX-008: Insufficient feedback on user interaction
- HELIX-009: Limited interactivity for the input fields


## Reproduction Steps

Look at the input fields and observe if there are any indications of guidance.

## Evidence

The input fields have no visible placeholders, help icons, or other means of conveying guidance to the user.

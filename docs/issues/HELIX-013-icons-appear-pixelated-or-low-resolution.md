# Icons appear pixelated or low-resolution

Some of the app icons (e.g., IPTV, VLC) in the background appear slightly pixelated or not optimized for the resolution, which can diminish the visual quality.

## Evidence

The IPTV and VLC icons in the 'Favorite Apps' section show visibly pixelated edges.

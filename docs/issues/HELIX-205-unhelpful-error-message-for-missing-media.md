# Unhelpful error message for missing media

The error message 'Media not found' is too generic and does not provide any guidance on what the user should do next or why the media is missing. This can lead to user confusion and frustration.

## Reproduction Steps

Attempt to access media that does not exist or is unavailable.

## Evidence

Text 'Media not found' displayed prominently on the screen.

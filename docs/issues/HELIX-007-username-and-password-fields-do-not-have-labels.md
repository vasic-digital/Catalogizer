# Username and password fields do not have labels

The username and password fields do not have labels, which can make it difficult for users to understand what information is required in each field.

## Related Issues

- HELIX-001: Insecure Password Input
- HELIX-002: Lack of Feedback on Form Submission
- HELIX-003: Inconsistent Label Alignment
- HELIX-004: Lack of Placeholder Text
- HELIX-005: Inconsistent Button Styling
- HELIX-006: Password field does not have a show password option


## Reproduction Steps

Look at the username and password fields and try to determine what information is required in each field.

## Evidence

The username and password fields do not have any text or other indicators that identify what information is required in each field.

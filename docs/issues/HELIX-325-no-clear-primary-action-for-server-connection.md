# No clear primary action for server connection

The 'Discover' and 'Connect' buttons are placed side by side without clear visual hierarchy, which could confuse users about the primary action.

## Evidence

Both 'Discover' and 'Connect' buttons appear equally prominent, with no clear indication of which one to use first.

# Incomplete user authentication/onboarding process

The app's welcome screen does not provide clear instructions or prompts for new users to complete the onboarding process, such as signing up, entering personal details, or connecting to a social media account. This could create frustration and prevent potential users from engaging with the app.

## Related Issues

- HELIX-090: Missing navigation labels for customization options


## Evidence

There are no visible elements like button prompts or instructional text that direct new users on what their next steps should be in order to fully utilize the app's features.

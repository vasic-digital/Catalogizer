# Lack of descriptive placeholder text in input fields

The input fields for 'Username' and 'Password' do not have placeholder text to guide users on what to enter, which can hinder accessibility for users unfamiliar with the application.

## Evidence

Both 'Username' and 'Password' fields are blank by default when no input is provided.

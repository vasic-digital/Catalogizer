# Inconsistent movie card aspect ratios

The movie thumbnails have inconsistent aspect ratios, causing misalignment and a disjointed visual appearance. This disrupts the grid layout and makes the interface look unpolished.

## Evidence

The first movie card ('21 Grams') is in portrait orientation, while the others are in landscape or square formats.

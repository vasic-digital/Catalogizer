# Insufficient feedback on user interaction

There is no immediate visual feedback when users interact with the buttons. This lack of feedback can make it difficult for users to understand whether their actions have been successfully registered.

## Related Issues

- HELIX-001: Misplaced elements in sign-up form
- HELIX-002: Inconsistent text styling
- HELIX-003: Cluttered input fields
- HELIX-004: Lack of clear feedback for user input
- HELIX-005: Inadequate spacing between fields and buttons
- HELIX-007: Inconsistent button labeling


## Reproduction Steps

Click on either the 'Sign In' or 'Server Connection' button and observe any visual changes on the interface.

## Evidence

There are no visible animations, colors changing, or any other indication of the user's interaction with the buttons.

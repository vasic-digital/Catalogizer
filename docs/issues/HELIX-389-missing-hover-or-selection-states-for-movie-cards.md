# Missing hover or selection states for movie cards

There are no visible hover, focus, or selection states on the movie cards, which can make it unclear to users if an item is interactive or selected. This reduces usability, especially for keyboard or touch users.

## Evidence

No visual feedback (e.g., border, shadow, or color change) is visible on any movie card.

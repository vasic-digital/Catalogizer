# Low contrast for unselected library category buttons

The text for unselected library categories (e.g., 'Comics', 'Software', 'TV Shows', 'Books') has extremely low contrast against the dark background of the buttons. This makes the category names nearly unreadable, significantly impacting usability and accessibility for users, especially those with visual impairments.

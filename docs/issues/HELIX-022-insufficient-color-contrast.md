# Insufficient Color Contrast

The color contrast between the background and the text is insufficient, which may make it difficult for users with visual impairments to read the text.

## Related Issues

- HELIX-012: Insufficient color contrast


## Reproduction Steps

Observe the color contrast between the background and the text.

## Evidence

The color contrast between the background and the text does not meet the WCAG guidelines for sufficient color contrast.

# Input fields lack visible labels or instructions for assistive technologies

There is no indication that input labels are tied to the input fields programmatically, potentially causing issues for screen readers.

## Evidence

The labels ('Username', 'Password', 'Server URL') do not appear to be explicitly associated with the input boxes.

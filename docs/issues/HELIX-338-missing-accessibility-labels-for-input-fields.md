# Missing accessibility labels for input fields

The 'Username' and 'Password' input fields lack associated labels or ARIA attributes, making it difficult for screen readers to identify the purpose of each field.

## Evidence

No visible ARIA labels or screen-reader-only text associated with the input fields.

# No option to recover forgotten credentials

There is no visible link or option for users to recover forgotten usernames or passwords. This could lead to user frustration and abandonment if they cannot log in.

## Evidence

No 'Forgot Password?' or 'Forgot Username?' link is visible on the screen.

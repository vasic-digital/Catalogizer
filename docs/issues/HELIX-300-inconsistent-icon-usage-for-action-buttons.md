# Inconsistent icon usage for action buttons

The 'Play' button prominently features a triangular play icon, whereas the adjacent 'Back to Library' and 'Favorite' buttons are text-only and lack corresponding icons. This creates an inconsistency in the visual design language for primary action buttons. For example, a 'Favorite' button commonly includes a heart or star icon for intuitive recognition.

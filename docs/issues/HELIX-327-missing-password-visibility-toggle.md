# Missing password visibility toggle

The password field does not have a visibility toggle (eye icon), which is a common UX pattern. This makes it difficult for users to verify their input and correct mistakes, potentially leading to login failures.

## Evidence

The 'Password' field lacks an eye icon or any other indicator for toggling visibility.

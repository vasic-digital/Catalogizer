# No retry or reload mechanism for failed media load

There is no option for users to retry loading the media, which could be a temporary issue. This forces users to manually navigate back and try again, creating unnecessary friction.

## Evidence

The UI lacks a 'Retry' or 'Reload' button to attempt fetching the media again.

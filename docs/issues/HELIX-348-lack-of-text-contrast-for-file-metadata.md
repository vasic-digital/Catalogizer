# Lack of text contrast for file metadata

The text showing file metadata (e.g., file size and type) has low contrast against the dark background, making it difficult to read for users with visual impairments.

## Evidence

The text 'DOC', '196K', '196', and 'JPG' appears in a light gray color on a dark gray background.

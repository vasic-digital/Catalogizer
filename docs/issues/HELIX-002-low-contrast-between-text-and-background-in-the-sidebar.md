# Low contrast between text and background in the sidebar

The text for the toggle labels (Recommended, Subscriptions, Trending) and the sidebar has insufficient contrast against the dark background, potentially causing readability issues for users with visual impairments.

## Evidence

Text in the sidebar is a light font on a dark background, which might not have sufficient color contrast.

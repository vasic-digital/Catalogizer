# Missing alt text or labels for app icons

App icons in the Favorite Apps section lack visible text labels, which could make it difficult for screen reader users to identify the apps.

## Reproduction Steps

Observe the Favorite Apps section and note the absence of text labels under icons.

## Evidence

Icons like VLC and NOVA do not have visible text labels, only graphical icons.

# Button with incorrect text

The 'Sign in' button should likely be labeled 'Log in', as this is a common term for the action.

## Reproduction Steps

Navigate to the login screen and observe the button label.

## Evidence

The button label says 'Sign in', which deviates from standard usage of 'sign in' to mean 'create an account'. This could lead to confusion among users.

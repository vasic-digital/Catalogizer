# Inconsistent navigation labels

The navigation menu items are labeled inconsistently, which can lead to confusion for users in trying to navigate the application. Inconsistent labeling may cause users to take longer to understand the app structure and hinder the overall user experience.

## Reproduction Steps

Navigate to different screens within the application to observe the navigation labels

## Evidence

The first item in the menu is labeled 'Home' while the second item is labeled 'TV' without specifying what type of TV programming is included. This inconsistency can be confusing for users trying to find specific content. The third item, 'Movies', is also missing a label, which may cause uncertainty about whether it leads to movies or another type of content.

# Ambiguous server connection options

The 'Server Connection' section is not clearly labeled as optional or required, and the meaning of 'Discovery' and the refresh icon is unclear to the user.

## Evidence

The presence of discovery and refresh options next to the server URL lacks helper text or clarity on their functionality.

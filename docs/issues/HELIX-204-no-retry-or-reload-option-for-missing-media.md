# No retry or reload option for missing media

There is no option for users to retry loading the media, which could be a temporary issue (e.g., network error). This forces users to manually navigate back and try again.

## Reproduction Steps

Encounter a 'Media not found' error and attempt to reload or retry accessing the media.

## Evidence

No 'Retry' or 'Reload' button is present on the screen.

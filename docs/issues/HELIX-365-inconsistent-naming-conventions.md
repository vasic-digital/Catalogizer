# Inconsistent naming conventions

The titles in the 'Recently Added Software' section use inconsistent naming conventions. Some include years, some do not, and one includes additional metadata (e.g., 'Bas Celik 1950'). This inconsistency can confuse users and make the catalog appear unprofessional.

## Evidence

'Suicide Kings' includes a year (1997) in a different format, while 'Being John Malkovich' and 'Fountain' do not include years.

# Insufficient contrast between text and background

The image shows a user interface with a partially completed form, where some input fields are missing or have already been filled in. These could create confusion for users trying to complete the form.

## Reproduction Steps

1. Open the application, 2. Access the form, 3. Observe that the input fields are not fully visible or populated with the appropriate default values or options.

## Evidence

The text 'Forget Password' in the screenshot does not have sufficient contrast with the background, which might make it difficult for users to read, especially those with visual impairments.

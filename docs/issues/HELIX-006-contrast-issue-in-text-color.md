# Contrast issue in text color

The text on the logo has low contrast against the background, which may make it difficult for users with visual impairments to read. This could potentially hinder accessibility.

## Reproduction Steps

Open the application

## Evidence

The image shows the text in a light color that does not stand out well against the darker background.

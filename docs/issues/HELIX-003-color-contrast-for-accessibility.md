# Color Contrast for Accessibility

The color contrast between the placeholder text and the background is quite low, especially in a dark environment. This could pose accessibility issues for users with visual impairments. Improving the contrast would help to ensure that the placeholders are legible to all users.

## Evidence

The placeholder text 'Coinhunter' is difficult to read against the dark background due to low color contrast.

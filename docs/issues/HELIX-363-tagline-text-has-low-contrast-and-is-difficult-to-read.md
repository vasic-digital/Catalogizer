# Tagline text has low contrast and is difficult to read.

The text "Your media collection, organized." located below the application name is a light blue/gray color on a dark blue background. Its small font size and insufficient contrast make it challenging to read quickly and clearly. This impacts accessibility for users with visual impairments and general readability for all users, hindering quick understanding of the application's purpose.

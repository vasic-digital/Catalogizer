# Insufficient contrast for secondary instructional text.

The text "Use the web dashboard to configure storage and trigger scans." uses a very light gray color on the dark background. Visually, this text is difficult to read. Based on common dark theme color palettes, if the text color is similar to #888888 and the background is #181818, the contrast ratio is approximately 4.13:1. This fails the WCAG 2.1 AA requirement of a minimum contrast ratio of 4.5:1 for normal text, making it challenging for users with visual impairments or in certain viewing conditions to read.

# Missing onboarding or guidance for new users

There is no onboarding flow, tutorial, or hint system to guide new users on how to use the app. This increases the risk of users abandoning the app due to lack of understanding of its purpose or functionality.

## Reproduction Steps

Open the application for the first time.

## Evidence

No instructional text, tooltips, or call-to-action buttons visible on the empty state screen.

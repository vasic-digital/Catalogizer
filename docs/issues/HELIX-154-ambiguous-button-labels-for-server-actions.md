# Ambiguous button labels for server actions

The 'Discover' and 'Connect' buttons are unclear in their purpose, as 'Discover' could imply searching for servers, while 'Connect' suggests establishing a connection. This may confuse users.

## Evidence

Unclear distinction between 'Discover' and 'Connect' button functionality.

# Inconsistent or mismatched design elements

The user interface includes various design elements, such as buttons and menus, that may not be consistent with one another. This can lead to a disjointed user experience.

## Related Issues

- HELIX-030: Button Label Mismatch


## Reproduction Steps

To reproduce this issue, one would need to navigate through the app's interface and examine the consistency of design elements throughout the application.

## Evidence

The presence of different style buttons or menus suggests inconsistency in the design elements.

# Lack of meaningful metadata for media items

The UI does not display any useful metadata (e.g., title, duration, resolution) for the recently added items, reducing usability and discoverability.

## Reproduction Steps

Check the 'Recently Added' section for any metadata or descriptive information.

## Evidence

Only filenames and file size (e.g., '1.9GB') are shown; no titles, descriptions, or thumbnails with context.

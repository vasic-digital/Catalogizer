# Inconsistent input field styling

The 'Username' input field has a visible border and a light background, while the 'Password' input field appears as a simple underline without a clear boundary, leading to inconsistent visual design.

## Evidence

The 'Username' field has a rectangular border, but the 'Password' field only has a bottom underline.

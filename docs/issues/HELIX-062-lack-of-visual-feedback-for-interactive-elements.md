# Lack of visual feedback for interactive elements

The 'Customize your Home screen' and 'Send feedback' cards lack visual feedback (e.g., hover, ripple, or highlight) to indicate interactivity, which may confuse users.

## Evidence

Cards appear static with no visible interactive states.

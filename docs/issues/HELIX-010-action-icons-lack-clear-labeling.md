# Action icons lack clear labeling

Buttons such as 'Play,' 'Back to Library,' and 'Favorite' do not have visible tooltips or descriptions for screen readers, which may hinder usability for some users.

## Related Issues

- HELIX-006: Lack of clear hover or focus states


## Evidence

Icons are only identified by their text, which may not be accessible for all user scenarios.

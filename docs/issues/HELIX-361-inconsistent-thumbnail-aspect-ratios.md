# Inconsistent thumbnail aspect ratios

The thumbnails for the recently added software have inconsistent aspect ratios, leading to a visually unappealing and disorganized layout. Consistent aspect ratios improve visual harmony and user experience.

## Evidence

Thumbnails for 'Being John Malkovich', 'Fountain', and 'Suicide Kings' appear to be cropped differently, while 'Cudotvorni mac (Bas Celik 1950)' has a circular logo instead of a rectangular thumbnail.

# No placeholder text or examples in input fields

The 'Username' and 'Password' fields lack placeholder text or examples, which could help users understand the expected input format. This may lead to confusion, especially for new users.

## Evidence

The 'Username' and 'Password' fields are empty with no placeholder text or examples.

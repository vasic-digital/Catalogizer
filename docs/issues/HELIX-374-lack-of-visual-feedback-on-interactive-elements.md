# Lack of visual feedback on interactive elements

The buttons do not provide clear visual feedback (e.g., hover, press states), which can reduce user confidence in interaction.

## Evidence

No visible hover or press states on the 'Play', 'Back to Library', or 'Favorite' buttons.

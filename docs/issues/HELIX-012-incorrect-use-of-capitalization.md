# Incorrect use of capitalization

The button text on the form should be in lowercase, as it is standard for user interfaces. However, this particular form incorrectly uses uppercase for 'CATALOGIZER'. This can create confusion and visual clutter.

## Related Issues

- HELIX-004: Text overlapping with background


## Evidence

In the image, you can see that the form has a button labeled 'CATALOGIZER', which is in uppercase. This is inconsistent with most modern user interfaces where such terms are typically styled in lowercase to maintain consistency.

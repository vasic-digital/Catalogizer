# Missing screen reader support for empty state

The empty state lacks ARIA labels or alt text for the icon, which can make it difficult for screen reader users to understand the purpose of the screen or the icon.

## Reproduction Steps

Use a screen reader to navigate the empty state screen.

## Evidence

No visible alt text or ARIA labels associated with the icon.

# Lack of loading progress indicator

The loading message does not include a progress bar or percentage, leaving users uncertain about how long the loading process will take. This can lead to frustration or confusion about whether the app is working.

## Evidence

Only a spinning loader and static text 'Loading your media collection...' are shown without any progress feedback.

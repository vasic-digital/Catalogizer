# Placeholder text in input fields is not descriptive

The placeholder text for 'Username' and 'Password' fields is just a repetition of the label. Placeholder text should provide additional context or an example (e.g., 'Enter your username').

## Evidence

Placeholder text reads 'Username' and 'Password' instead of providing examples or instructions.

# Low contrast for placeholder text in input fields

The placeholder text in the input fields has low contrast against the background, making it difficult for users with visual impairments to read.

## Evidence

The placeholder text 'Username', 'Password', and 'http://localhost:8080' is light gray on a white or dark background.

# Inconsistent border radius among action buttons

The 'Favorite' button appears to have a slightly more rounded (higher border-radius) style than the 'Play' and 'Back to Library' buttons, which have a subtly less rounded shape. This creates a minor visual inconsistency among interactive elements that should ideally share a consistent design language.

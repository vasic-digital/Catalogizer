# Insecure Password Input

The password input field does not display a password visibility toggle button, which is a common UX pattern that allows users to view their password in plain text. This can lead to user frustration and potential security issues if the user enters an incorrect password multiple times.

## Reproduction Steps

None

## Evidence

The password input field does not have a password visibility toggle button.

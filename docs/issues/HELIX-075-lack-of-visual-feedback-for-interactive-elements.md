# Lack of visual feedback for interactive elements

The interactive elements such as 'Customize your Home screen' and 'Send feedback' do not provide visual feedback (e.g., hover or pressed states) to indicate interactivity. This can confuse users about whether these elements are clickable.

## Evidence

No visible hover, pressed, or focus states on the interactive cards.

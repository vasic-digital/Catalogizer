# Low contrast for category names in library filter tags

The text identifying the category names (e.g., 'Movies', 'Comics', 'Software', 'TV Shows', 'Books') within the library filter tags has insufficient contrast against the dark background. While the numerical counts are clearly visible, the category names themselves are very dim and difficult to read, impacting general readability and accessibility.

# Inconsistent branding on app screens

There are inconsistencies in the branding elements such as app name and logo, which may confuse users. This could affect the user experience and create a fragmented brand presence.

## Evidence

The app name at the top of the screen is different from the one on the login/welcome page, and the logo appears in both places but has a slight variance in color.

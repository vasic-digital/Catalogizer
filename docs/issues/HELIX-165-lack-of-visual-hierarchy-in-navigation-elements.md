# Lack of visual hierarchy in navigation elements

The app's navigation menu appears to have text links without clear visual hierarchy, which could make it difficult for users to discern the importance or purpose of each link. This may impact the user experience and create confusion.

## Related Issues

- HELIX-048: Icons do not convey their meaning
- HELIX-091: Icons not aligned within the menu
- HELIX-092: Prominent use of capital letters


## Evidence

There are no distinguishing visual elements like icons, different font sizes, or contrasting colors that help users quickly identify which menu item is most relevant to them.

# Insufficient contrast for 'Search' button text.

The text 'Search' on the button located at the top right of the screen has extremely low contrast against its dark background. This makes the text very difficult, if not impossible, to read for users, especially those with visual impairments, failing WCAG contrast ratio guidelines.

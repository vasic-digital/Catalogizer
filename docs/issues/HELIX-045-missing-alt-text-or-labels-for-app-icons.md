# Missing alt text or labels for app icons

App icons in the Favorite Apps section lack text labels, which may make it difficult for screen reader users to identify the apps.

## Reproduction Steps

Observe the Favorite Apps section and note the absence of visible labels for each app icon.

## Evidence

Only some icons (e.g., KODI) have visible text labels, while others do not.

# Social login icons are generic or incorrect.

The icons used for Google and Apple social login (a 'G' and a stylized apple-like symbol) do not match the official, recognizable brand logos. Using generic or incorrect icons can reduce user trust, recognition, and the overall professional appearance of the application.

# Inconsistent font size

The font size of the text in the search bar is smaller than the font size of the text in the rest of the application. This inconsistency may make the application look less polished and professional.

## Reproduction Steps

Open the application and compare the font size of the text in the search bar with the font size of the text in the rest of the application.

## Evidence

The font size of the text in the search bar is 12px, while the font size of the text in the rest of the application is 14px.

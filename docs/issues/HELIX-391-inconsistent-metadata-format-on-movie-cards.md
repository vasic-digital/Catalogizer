# Inconsistent metadata format on movie cards

The metadata (year and rating) on the movie cards is formatted inconsistently. Some cards show the year and rating, while others only show one or none, which can confuse users.

## Evidence

The first card shows '2003' and '7.3', the second shows only '2017', the third shows '2021' and '6.4', and the last shows only '6.5'.

# Crowded interface elements

The interface appears to have an excessive amount of information or content within a single element, which can create visual clutter and overwhelm users. This may negatively impact the usability of the interface.

## Related Issues

- HELIX-043: Imbalanced layout designation
- HELIX-044: Unclear call-to-action placement
- HELIX-045: Inconsistent design elements
- HELIX-046: Lack of clear feedback for interactions


## Reproduction Steps

Review the organization of text and images in each element of the interface to ensure that essential information is clearly conveyed without overcrowding.

## Evidence

The 'Message' button contains multiple lines of text, some of which may not be immediately relevant or necessary.

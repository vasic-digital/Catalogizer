# Ineffective contrast on button labels

The button labels have low contrast with the background, making them hard to read for users who are visually impaired. This can cause accessibility issues.

## Related Issues

- HELIX-004: Text overlapping with background
- HELIX-012: Incorrect use of capitalization
- HELIX-015: Button label misalignment


## Reproduction Steps

Check the screenshot for the textual elements of the user interface and observe the contrast between the text and the background.

## Evidence

In the image, the button labels do not stand out well against the background, making it difficult to distinguish them.

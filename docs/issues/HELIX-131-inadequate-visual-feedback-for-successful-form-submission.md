# Inadequate visual feedback for successful form submission

There is no clear visual feedback when a user successfully submits a form. The 'Success' message could be more prominent and designed in a way that ensures the user notices it.

## Reproduction Steps

Attempt to submit the form and observe if there is any clear visual indication of success.

## Evidence

There is no visible feedback or message after successfully submitting the form.

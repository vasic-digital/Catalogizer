# No feedback for server connection status

The 'Discover' and 'Connect' buttons under 'SERVER CONNECTION' do not provide any visual feedback or status indication (e.g., loading spinner, success/error message). Users may be unsure if the action was successful or if they need to retry.

## Evidence

No visual feedback (e.g., loading state, success/error message) is present for the Discover and Connect buttons.

# No feedback for server connection status

The 'Discover' and 'Connect' buttons do not provide any visual feedback (e.g., loading spinner, success/error message) when pressed. Users may be unsure if the action was successful or if the app is processing the request.

## Evidence

No loading indicators or status messages near 'Discover' or 'Connect' buttons.

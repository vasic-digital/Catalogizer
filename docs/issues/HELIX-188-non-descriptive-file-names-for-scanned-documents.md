# Non-descriptive file names for scanned documents

The recently added files have non-descriptive names like 'сканирование0052.jpg'. This makes it difficult for users to identify the content of the files without opening them.

## Evidence

File names such as 'сканирование0052.jpg', 'сканирование0034.jpg', and 'сканирование0023.jpg' are visible in the 'Recently Added' section.

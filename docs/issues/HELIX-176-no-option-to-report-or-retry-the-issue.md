# No option to report or retry the issue

There is no option for the user to report the issue or retry loading the media, which could leave users stuck without a resolution.

## Reproduction Steps

Trigger the 'Media not found' error and look for options to retry or report.

## Evidence

No buttons or links for retrying or reporting the issue are present.

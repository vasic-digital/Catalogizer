# Lack of visual feedback for user interaction

There is no visible indication that an action has been performed when a user signs up or signs in. Visual feedback such as a loading bar, a message confirming the action, or a change in the UI state would help users understand what is happening.

## Related Issues

- HELIX-013: Lack of clear call-to-action
- HELIX-014: Lack of clear form labels
- HELIX-016: Lack of clear label on button
- HELIX-017: Inconsistent font sizes for important information


## Reproduction Steps

Perform an action on the login screen (e.g., sign in).

## Evidence

No visible indication of the action being performed.

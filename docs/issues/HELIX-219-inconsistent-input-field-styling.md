# Inconsistent input field styling

The 'Username' input field has no visible border or background contrast, making it appear disabled or less interactive compared to the 'Password' field, which has a clear white border.

## Evidence

The 'Username' field is barely visible against the dark background, while the 'Password' field has a distinct white border.

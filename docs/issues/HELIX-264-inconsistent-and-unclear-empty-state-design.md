# Inconsistent and unclear empty state design

The empty state of the application lacks any informative or guiding elements. Users are presented with a blank screen and a small icon, which does not communicate what the app does or how to proceed. This can lead to confusion and a poor first-time user experience.

## Reproduction Steps

Open the application when no content or data has been added yet.

## Evidence

Blank screen with only a small icon in the center and no text or actionable elements.

# No retry or reload option for missing media

There is no option for users to retry loading the media, which could be a simple fix if the issue was temporary (e.g., network interruption). This forces users to navigate back without attempting to resolve the issue.

## Evidence

Only a 'Back' button is present; no 'Retry' or 'Reload' option is available.

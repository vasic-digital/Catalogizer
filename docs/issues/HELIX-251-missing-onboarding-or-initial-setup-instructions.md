# Missing onboarding or initial setup instructions

There is no indication of how to start using the app or what the next steps are. Users may not understand the app's purpose or how to populate it with data, resulting in a poor first-time user experience.

## Reproduction Steps

Launch the application for the first time or navigate to a section with no user-generated content.

## Evidence

Absence of any instructional text, placeholder examples, or prompts for user action.

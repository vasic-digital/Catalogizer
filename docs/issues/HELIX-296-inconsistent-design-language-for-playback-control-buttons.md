# Inconsistent design language for playback control buttons.

There is a lack of consistency in the visual design of the playback controls. The main 'Play' button in the center is a large, circular, icon-only button, while all other primary playback controls in the bottom bar (e.g., '-10s', '+10s', '1.0x', 'Audio', 'Off', and the second 'Play' button) are smaller, rectangular buttons that combine an icon with descriptive text. This inconsistency in shape, size, and labeling creates a disjointed user experience and visual clutter.

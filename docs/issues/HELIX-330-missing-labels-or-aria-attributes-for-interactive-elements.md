# Missing labels or ARIA attributes for interactive elements

The 'Discover' and 'Connect' buttons lack visible labels or ARIA attributes, which could make it difficult for screen reader users to understand their purpose.

## Evidence

The 'Discover' and 'Connect' buttons only have icons without accompanying text or ARIA labels.

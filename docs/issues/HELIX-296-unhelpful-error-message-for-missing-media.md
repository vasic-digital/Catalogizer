# Unhelpful error message for missing media

The error message 'Media not found' is too generic and does not provide any guidance on why the media is missing or how to resolve the issue. This can frustrate users and lead to a poor user experience.

## Reproduction Steps

Attempt to access media that does not exist or is unavailable in the application.

## Evidence

Text displayed on the screen reads 'Media not found' without additional context or instructions.

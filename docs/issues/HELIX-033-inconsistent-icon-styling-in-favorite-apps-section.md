# Inconsistent icon styling in Favorite Apps section

The icons for IPTV, RUTUBE, VLC, NOVA, and KODI have inconsistent styling, with some having transparent backgrounds and others having solid or gradient backgrounds. This inconsistency disrupts visual harmony.

## Evidence

IPTV and KODI icons have solid dark backgrounds, while RUTUBE, VLC, and NOVA have varied and inconsistent backgrounds.

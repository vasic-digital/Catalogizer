# Inconsistent visual hierarchy for input fields

The 'Server URL' input field appears in a lower visual hierarchy due to a different design treatment compared to 'Username' and 'Password', which might confuse users about its importance.

## Evidence

The 'Server URL' field has no shadowing or consistent visual alignment relative to the above fields.

# No feedback for server connection status

There is no visible feedback (e.g., loading spinner, success/error message) for the 'Discover' or 'Connect' actions, leaving users uncertain about the status of their request.

## Evidence

No status indicators near the 'Discover' and 'Connect' buttons.

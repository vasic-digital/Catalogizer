# Inconsistent button labeling

The 'Sign In' and 'Server Connection' buttons have different labels than their corresponding input fields. This inconsistency can be confusing for users and may hinder usability.

## Related Issues

- HELIX-001: Misplaced elements in sign-up form
- HELIX-002: Inconsistent text styling
- HELIX-003: Cluttered input fields
- HELIX-004: Lack of clear feedback for user input
- HELIX-005: Inadequate spacing between fields and buttons


## Reproduction Steps

Click on the 'Sign In' or 'Server Connection' button and observe the input fields.

## Evidence

The 'Sign In' button is labeled as such, while the corresponding input field has a different label. Similarly, the 'Server Connection' button does not match the input field.

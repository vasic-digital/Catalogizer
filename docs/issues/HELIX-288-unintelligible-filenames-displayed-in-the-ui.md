# Unintelligible filenames displayed in the UI

The filenames under 'Recently Added' are in an unreadable format (e.g., 'сканирование0052.jpg'). This makes it difficult for users to identify content without opening each file.

## Reproduction Steps

Observe the filenames listed under the 'Recently Added' section.

## Evidence

Filenames such as 'сканирование0052.jpg', 'сканирование0034.jpg', etc., are not user-friendly.

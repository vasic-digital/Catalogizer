# Password field does not have a show password option

The password field does not have a show password option, which can make it difficult for users to verify that they have entered their password correctly.

## Related Issues

- HELIX-001: Insecure Password Input
- HELIX-002: Lack of Feedback on Form Submission
- HELIX-003: Inconsistent Label Alignment
- HELIX-004: Lack of Placeholder Text
- HELIX-005: Inconsistent Button Styling


## Reproduction Steps

Enter a password in the password field and try to verify it.

## Evidence

The password field does not have an eye icon or any other indicator that allows the user to view the password they have entered.

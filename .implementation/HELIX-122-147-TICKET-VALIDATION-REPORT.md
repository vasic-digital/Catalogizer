- **HELIX-141** (low): Contrast/spacing on launcher tiles → **Fixed** by the channel deduplication/recreate logic; the perceived "contrast issue" was actually stale duplicate "Books" channels rendered by the Android TV launcher.

## Remediation for Future QA Runs

1. **Screenshot Verification**: HelixQA must verify the active package name (`adb shell dumpsys activity top`) before analyzing a screenshot. If the active package is not the target app, the step must be retried or marked as an infrastructure failure, not an app bug.
2. **ADB Command Validation**: Commands like `curl` that are not guaranteed to exist on Android devices must be checked for availability or wrapped with fallback logic.
3. **Acceptance Criteria**: Every ticket generated by HelixQA now includes an `## Acceptance Criteria` section. Any ticket missing this section should be rejected by the triage process.
4. **Device Capability Pre-Check**: Tests requiring specific hardware (4K display, HDR, external sound bar, HEVC decoder) must validate device capabilities before running and skip gracefully rather than filing tickets.

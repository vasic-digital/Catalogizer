# Missing visual focus indicator for selected app.

There is no discernible visual indicator (e.g., a highlight, border, or glow) on any of the app icons in the 'Favorite Apps' row to show which app is currently in focus. This is a critical usability issue for TV interfaces navigated by remote control, as users need clear visual feedback on their current selection.

## Related Issues

- HELIX-001: App icon partially obscured by adjacent icon in 'Favorite Apps' row.


## Evidence

No app icon in the 'Favorite Apps' row has any visual treatment (like the underline for 'Home' in the top navigation) to indicate it is currently selected or focused.

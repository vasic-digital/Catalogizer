# Inconsistent capitalization styles across different UI text elements and headers.

The application uses a mix of capitalization styles for its text elements. 'CATALOGIZER' and 'SERVER CONNECTION' are displayed in ALL CAPS, while 'Media Collection Manager', 'Username', 'Password', 'Sign In', 'Server URL', and 'Connected to server' use Title Case or sentence case. Consistent capitalization throughout the UI (e.g., all headers in Title Case or all in ALL CAPS) would improve visual consistency and professionalism.

Observed capitalization for 'CATALOGIZER' (ALL CAPS), 'Media Collection Manager' (Title Case), 'SERVER CONNECTION' (ALL CAPS), and 'Server URL' (Title Case).

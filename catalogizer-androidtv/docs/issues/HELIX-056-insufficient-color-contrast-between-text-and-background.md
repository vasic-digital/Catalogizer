# Insufficient color contrast between text and background

The text color is not sufficiently different from the background color, making it difficult for users with visual impairments to read.

## Related Issues

- HELIX-005: Low contrast for descriptive text in cards.
- HELIX-018: Low contrast and small font size for 'Favorite Apps' label.
- HELIX-040: Inaccessible Color Scheme
- HELIX-045: Insufficient Color Contrast
- HELIX-053: Lack of Color Contrast


## Reproduction Steps

None

## Evidence

The text color is a light gray (#ccc) on a dark gray (#333) background, which does not meet the WCAG 2.1 contrast ratio requirements.

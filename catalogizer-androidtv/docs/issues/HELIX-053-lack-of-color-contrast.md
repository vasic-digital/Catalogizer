# Lack of Color Contrast

The application does not have sufficient color contrast between the background and text. This can make it difficult for users with visual impairments to read the text.

## Related Issues

- HELIX-005: Low contrast for descriptive text in cards.
- HELIX-018: Low contrast and small font size for 'Favorite Apps' label.
- HELIX-040: Inaccessible Color Scheme
- HELIX-045: Insufficient Color Contrast


## Reproduction Steps

None

## Evidence

The background color of the application is dark gray, and the text color is light gray.

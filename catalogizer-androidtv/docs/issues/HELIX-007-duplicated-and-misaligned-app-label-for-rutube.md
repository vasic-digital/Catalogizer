# Duplicated and misaligned app label for 'RUTUBE'.

The 'RUTUBE' app icon has 'RUTUBE' text displayed as part of its icon. Below this, there is another instance of 'RUTUBE' text which is smaller, misaligned, and partially overlaps with the bottom of the app icon itself. This creates visual clutter and is a rendering error.

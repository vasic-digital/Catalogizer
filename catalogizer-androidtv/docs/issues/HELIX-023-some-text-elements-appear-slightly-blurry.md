# Some text elements appear slightly blurry

The text displaying the 'Server URL' value ('http://192.160.0.2:30000') and the status message 'Connected to server' appears slightly blurry or less sharp compared to other text elements like 'Username' or 'Password'. This may indicate a rendering issue, suboptimal font aliasing, or image compression artifacts, affecting the visual crispness of the UI.

## Evidence

The text 'http://192.160.0.2:30000' within the Server URL field and the 'Connected to server' message below it.

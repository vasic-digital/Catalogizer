# Ambiguity regarding 'Server URL' field editability

The 'Server URL' field displays a URL and features a green checkmark icon. It is unclear whether this field is editable for users to change the server address. If it is an input field, the checkmark within its boundaries is an unusual design for an active input state. If it is not editable, there is no clear indication or mechanism shown for users to configure or change the server URL, which could be a functional limitation.

## Evidence

The 'Server URL' field displaying 'http://192.160.0.2:30000' with a green checkmark icon to its right.

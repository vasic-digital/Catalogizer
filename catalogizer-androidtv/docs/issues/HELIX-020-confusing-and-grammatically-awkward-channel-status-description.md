# Confusing and grammatically awkward channel status description

The phrase 'Channels to empty' used as a description for both 'Alpharat' and 'Catalogue' channels is grammatically incorrect and unclear. It's ambiguous whether it indicates that the channel *is* currently empty or if it's an action to *make* the channel empty. This can confuse users about the actual status of these channels or what actions are available.

## Related Issues

- HELIX-019: Unclear placeholder text for a channel option


## Evidence

The text 'Channels to empty' displayed below 'Recommendations' for 'Alpharat' and below the icon for 'Catalogue' in the right-hand sidebar menu.

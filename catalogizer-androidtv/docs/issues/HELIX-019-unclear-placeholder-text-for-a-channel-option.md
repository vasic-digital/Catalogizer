# Unclear placeholder text for a channel option

The text 'Play here. Or' under the play icon at the top of the 'Customize channels' menu is ambiguous and appears to be incomplete or placeholder text. It provides no clear function or information about what this channel option represents, leading to user confusion.

## Evidence

The text 'Play here. Or' displayed directly under the blue play icon at the top of the right-hand sidebar menu.

# App icon partially obscured by adjacent icon in 'Favorite Apps' row.

The 'RUTUBE' app icon is almost entirely hidden behind the 'IPTV Pro' app icon. This prevents users from seeing the app, making it difficult or impossible to select or identify, indicating a significant layout issue for the 'Favorite Apps' section.

## Evidence

The 'RUTUBE' logo is clearly visible peeking out from behind the 'IPTV Pro' icon block on the left side.

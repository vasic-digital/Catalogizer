# Security: API Key Rotation Required

## Exposed Credentials Detected

The following API keys and tokens were present in `.env.resolved` and/or `HelixQA/.env` on the local filesystem and **MUST be rotated immediately** on their respective provider dashboards.

## Action Required

1. Log in to each service provider listed below.
2. Revoke the exposed key/token.
3. Generate a new key/token.
4. Update `HelixQA/.env` (and `.env` in the project root if applicable) with the new values.
5. Delete `HelixQA/.env.BACKUP_BEFORE_ROTATION` after rotation is complete.

## Notes

- `.env.resolved` has been removed from the working tree. It can be regenerated by `python resolve_env.py` when needed, but **must never be committed**.
- `HelixQA/.env.BACKUP_BEFORE_ROTATION` contains the old values for reference during rotation.
- All `.env*` files are covered by `.gitignore` and must remain untracked.

## Verification

After rotation, confirm no old keys remain in active use:
```bash
grep -R "YOUR_OLD_KEY_VALUE" .
```

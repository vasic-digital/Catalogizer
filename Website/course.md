# Video Course

Catalogizer offers comprehensive video training courses for users, administrators, and developers. The v2.3.0 curriculum contains 36 modules organized into three tracks. Modules 31-36 cover the v2.3.0 comprehensive completion work: database dialect rewriting, concurrency hardening, k6 stress testing, SonarQube/Snyk wiring, lazy/semaphore patterns, and universal test infrastructure with HelixQA.

---

## User and Admin Course (7 Modules)

Complete training from installation through administration and production deployment.

| Module | Title | Duration | Topics |
|--------|-------|----------|--------|
| 1 | Introduction & Installation | 45 min | Overview, system requirements, container/manual install, dynamic runtime detection |
| 2 | Getting Started | 75 min | Web UI, storage sources, browsing, search, analytics |
| 3 | Advanced Media Features | 75 min | Favorites, collections, playlists, subtitles, conversion |
| 4 | Multi-Platform Experience | 55 min | Android (offline mode, biometric auth, WebSocket), Android TV, Desktop, API client |
| 5 | Administration | 65 min | User management, security, monitoring, backup |
| 6 | Testing & Quality Assurance | 60 min | Go tests, Vitest, Playwright, challenge system (557+ challenges), security testing |
| 7 | Deployment & Production | 55 min | Container builds, Podman/Docker, production config, monitoring, Panoptic analytics |

**User/Admin Track Duration**: ~7 hours 10 minutes

---

## Developer Course (10 Modules)

In-depth technical training for building and extending Catalogizer.

| Module | Title | Duration | Topics |
|--------|-------|----------|--------|
| 1 | Introduction and Architecture | 45 min | System components, layered architecture, 41 submodules |
| 2 | Backend Development | 60 min | Go/Gin services, repository pattern, dependency injection |
| 3 | Authentication and Authorization | 45 min | JWT, RBAC, 2FA, biometric auth (Android), rate limiting |
| 4 | Media Detection and Processing | 75 min | Detection pipeline, analyzers, metadata providers, aggregation |
| 5 | Frontend Development | 60 min | React 18, TypeScript, Vite, React Query, Zustand, Tailwind |
| 6 | Real-Time Features and Protocols | 45 min | WebSocket event bus, SMB/FTP/NFS/WebDAV, circuit breaker |
| 7 | HTTP/3, Performance, and Stress Testing | 45 min | QUIC, Brotli, k6 load/stress/soak/spike tests |
| 8 | Desktop and Mobile Apps | 60 min | Tauri IPC, Kotlin/Compose MVVM, Leanback TV, offline sync |
| 9 | Module Architecture and Decoupling | 60 min | 22 Go modules, 9 TS modules, replace directives, submodule workflow |
| 10 | Security Scanning and Monitoring | 45 min | SonarQube, Semgrep, Snyk, Trivy, Prometheus, Grafana, alerting |

**Developer Track Duration**: ~9 hours

---

**Grand Total**: 17 modules, ~16 hours

## Certification Levels

- **Catalogizer User** -- Complete User/Admin Modules 1-4 with 80% assessment score
- **Catalogizer Administrator** -- Complete User/Admin Modules 1-7 with 80% assessment score
- **Catalogizer Developer** -- Complete all 10 Developer modules with 80% assessment score
- **Catalogizer Expert** -- Complete all 17 modules across both tracks with 80% assessment score

## Course Materials

Each module includes:
- Narrated video scripts with timestamps
- Slide presentations with speaker notes
- Hands-on exercises with step-by-step instructions
- Assessment quizzes with answer keys
- Reference code examples from the actual codebase
